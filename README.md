# 委員会出席カウントシステム

委員会ごとに委員・開催日を登録し、開催日ごとの出欠を記録して、月単位の出席回数・出席率を集計できるWebシステムです。

## 機能

- 委員会の登録・削除
- 委員会ごとの委員（役職名・氏名・事業所名）の登録・編集・削除
- 委員会ごとの開催日の登録・削除
- 開催日ごとの出欠記録（チェックボックスで出席者を選択）
- 月を指定して、委員ごとの出席回数・開催回数・出席率を集計表示（前月/次月ナビゲーション付き）
- **全体集計画面**: 全開催日 × 全委員の出欠マトリクス表示（○/空欄、開催日ごと・委員ごとの合計出席数）
- **出欠CSVインポート**: 月次の出欠CSV（氏名・出席/回答状況などの列）を取り込み、既存委員への反映・新規委員の自動登録・開催日の自動作成を行う（Shift_JIS/UTF-8いずれのCSVも対応）
- **個人別出席グラフ**: 全体集計画面で、委員ごとの出席回数を横棒グラフで可視化

## セットアップ

```bash
npm install
npm start
```

起動後、`http://localhost:3000` にアクセスします。ポートは環境変数 `PORT` で変更できます。

データは SQLite（`data/attendance.db`、初回起動時に自動作成）に保存されます。

## CSVインポートの形式

委員会詳細ページの「出欠CSVインポート」から、対象の開催日を指定してCSVファイルをアップロードします。

- 1行目は見出し行。以下の列名（いずれかの表記）が必要です。
  - 氏名: `氏名` または `名前`
  - 出席: `出席` または `回答状況`（`○`・`参加` を出席、空欄・`×`・`不参加` を欠席と判定）
  - 任意: `役職名`（`役職`）、`事業所名`（`会社名`）— CSVにしかいない新規委員を登録する際に使用
- 文字コードはUTF-8・Shift_JIS(CP932)のどちらでも自動判定します（Excelで保存したCSVもそのまま利用可能）。

例:
```csv
氏名,役職名,事業所名,回答状況
野島圭悟,委員長,株式会社DynoGames,参加
久保哉子,副委員長,株式会社LifeStyle,不参加×
```

## 技術構成

- Node.js / Express
- better-sqlite3（SQLite）
- EJS（サーバーサイドレンダリング）
- multer（CSVファイルアップロード）
- iconv-lite（CSVの文字コード自動判定・変換）
