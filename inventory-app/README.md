# 酒屋 備品発注・在庫管理システム

酒屋の備品（段ボール箱、紙コップ、ペーパータオル、ティッシュなど）の発注状況を、LINEのようなチャット入力で記録できるWebシステムです。スマホでのチャット入力と、PCでの管理画面（一覧・編集・集計）を分けて提供します。

## 主な機能

- **チャット入力**（スマホ想定）: 「紙コップ 10箱 発注」のように自然文で入力すると、品目・数量・発注先を自動解析して記録します。品目や数量が読み取れない場合は、ボットが質問し、ボタン（クイックリプライ）で回答できます。全員が同じチャット画面（グループチャットのような共有フィード）を見られます。
- **アカウント選択ログイン**: LINEのプロフィール選択のように、アカウントのアイコンをタップしてログインします（PIN設定時のみ入力）。複数名での利用を想定しています。
- **発注履歴**（スマホ／全ユーザー閲覧可）: 誰が・いつ・何を・どこに発注したかを検索できます。
- **管理画面**（PC想定、管理者権限）:
  - ダッシュボード（本日・今月の件数、よく発注される品目）
  - 発注記録の一覧・検索・編集・削除
  - 品目マスタ・発注先マスタ・アカウントの登録／編集
  - 日別・月別・年別の集計レポート（品目別／発注先別／発注者別の集計表とグラフ）

## セットアップ

```bash
npm install
npm start
```

起動後、`http://localhost:3000` にアクセスします。ポートは環境変数 `PORT` で変更できます。

データは SQLite（`data/inventory.db`、初回起動時に自動作成）に保存されます。

## 初期データ

初回起動時に以下が自動登録されます。

- 管理者アカウント: 名前「管理者」、PIN「0000」（管理画面の「アカウント管理」から他のスタッフを追加し、必要ならPINも設定してください）
- 発注先サンプル: アスクル、卸業者A、近隣スーパー、100円ショップ、Amazonビジネス
- 備品マスタ: 段ボール箱(大/中/小)、紙コップ、紙皿、ペーパータオル、ティッシュ、ゴミ袋、マスク、アルコール消毒液など約30品目

品目・発注先はいずれも管理画面から自由に追加・編集・無効化できます。

## チャット入力のコツ

- 品目名・数量（＋単位）・発注先が一文に含まれていれば、一度の入力で登録されます。
  - 例: 「紙コップ 10箱 発注」「ティッシュ3個をアスクルに発注して」
- 品目や数量が読み取れないときは、ボットが質問し、下に表示されるボタンから選ぶか、文字で回答すると続きから登録されます。
- 「キャンセル」「取消」と入力すると、質問中のやり取りを取り消せます。
- 「ヘルプ」と入力すると使い方を案内します。
- 発注先が省略された場合は未設定として記録され、あとから管理画面で編集できます。

## 技術構成

- Node.js / Express
- better-sqlite3（SQLite）
- EJS（サーバーサイドレンダリング）
- express-session（アカウント選択ログインのセッション管理）
- Chart.js（管理画面の集計グラフ、CDN読み込み）

## ディレクトリ構成

```
src/
  app.js          エントリーポイント（Express設定・ルーティング登録）
  db.js           SQLiteスキーマ定義・初期データ投入
  parser.js       チャット文からの品目・数量・発注先の解析
  queries.js      画面共通のDB参照関数
  middleware.js   ログイン必須・管理者権限チェック
  routes/
    auth.js       ログイン／ログアウト
    chat.js       チャット画面・メッセージ処理
    history.js    発注履歴（閲覧のみ）
    admin.js      管理画面（マスタ管理・発注記録編集・集計）
views/            EJSテンプレート（chat, history, login, admin/*）
public/           CSS・クライアントJS
```
